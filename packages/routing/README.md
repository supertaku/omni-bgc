# Offline conservative routing

Pure TypeScript engine and progress matcher. Mobile bridge: `apps/mobile/src/routing/index.ts`. Required `route(origin, entrance)` and `assessOrigin(origin)` signatures structurally match mobile `contracts.ts`. No native dependency, GPS permission, network request or persistence occurs here.

`installGraph(pack)` copies and validates a **trusted, independently reviewed pack**. The parent/data loader remains responsible for acquired-byte/hash authenticity, reviewed evidence identities, rights and exact version lineage before calling it. Runtime declarations are validation inputs, not a field survey, digital signature or license certificate. The engine does not promote candidate flags. Actual M3 candidate graph fails installation and all navigation remains unavailable.

`GraphPack` declares schema/version, raw source SHA256, supported single local simple polygon, pack review, source node identity/coordinate/grade/barrier, edge geometry/direction/access/foot/field review, and reviewed origin/entrance connectors. Current approved review requires a real UTC field-verification timestamp, unexpired validity and non-placeholder reviewer/evidence reference. Typed structure does not replace runtime checks. Self-crossing/open/degenerate/dateline/global boundaries, identity collisions, mismatched geometry and factors below one reject. Unsupported/outside geometry and unknown/restricted/stale/field-unverified edges exclude. Connectivity uses node IDs, never geometric crossings or coincident IDs. Cross-grade links require reviewed stairs/ramp/lift transitions. No wheelchair routing is exposed; `wheelchairRoutingAvailable()` is false.

GPS requires explicit confirmation, accuracy at most20m, observed age at most60s and no timestamp more than5s in the future. Manual/landmark origins require confirmation and valid WGS84. Origin assessment uses installed coverage when available. Every route requires an eligible entrance with a matching current approved entrance connector; no centroid or straight-line fallback. Search snaps to nearby eligible geometry within15m; on-network numerical tolerance is0.25m. Off-network traversal requires an exact reviewed origin connector anchored within1cm of the input origin, whose path is fully inside coverage. This deliberately refuses arbitrary nearby pins/GPS fixes when no safe connector is established.

Binary-heap A* uses spherical metre distance as an admissible heuristic. Edge costs are geometry length times a factor at least1; partial-edge geometry is sliced in direction, including same-edge and closed-loop journeys. Route result length is actual reconstructed geometry length, separate from weighted search cost. Instructions refer to approved path and connector labels; full turn-by-turn voice/landmark instruction QA is later work. Scope excursions, stale pack/edge/connector reviews, disconnected networks or unsafe origins return explicit unavailable reasons.

`matchProgress` returns ephemeral version/along-distance/segment/hysteresis state only. It rejects stale/inaccurate/duplicate/older fixes, matches a local progress window to avoid parallel-leg jumps, resists backwards jitter, needs three distinct off-route fixes to flag deviation and two recovery fixes. It never stores GPS coordinates or writes a saved route. UI owns any live memory state; precise location must not be persisted.

All successful route tests use SYNTHETIC TEST ONLY field/evidence claims; none approves actual geography. The real M3 candidate graph is exercised only for denial. Run `node --test tests/routing/mobile/engine.test.cjs` from repository root. Tests transpile TypeScript in memory using the installed mobile compiler, with no added dependencies or build artifacts.
