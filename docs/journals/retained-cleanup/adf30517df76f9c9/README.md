# Omni-BGC — Pre-AI Implementation Blueprint

This folder contains an execution-ready **plan**, not an already implemented mobile app. No codebase or real BGC dataset was audited in preparing this package. Source claims need per-milestone verification and legal permission review.

Start with `docs/PARENT_AGENT_START_PROMPT.md`, then `AGENTS.md` and `docs/IMPLEMENTATION_PLAN.md`.

- `docs/IMPLEMENTATION_PLAN.md`: scope, architecture, technology selection, data, UI, navigation, phases, acceptance gates and model/effort delegation.
- `AGENTS.md`: concise repository constraints and parent review standards.
- `docs/PARENT_AGENT_START_PROMPT.md`: ready-to-paste parent agent prompt. Start M0 only.
- `docs/DECISION_JOURNAL.md`: already populated architecture and product decision log, with templates.
- `docs/TOOL_RATIONALE.md`: why and how each tool is intended to be used.
- `docs/DATA_COLLECTION_PLAYBOOK.md`: detailed acquisition, verification and coverage program.
- `docs/UX_MAP_SPEC.md`: minimal low-friction map/Assistant shell UI contract.
- `docs/data-source-register/source-register.csv`: blank source licensing register.
- `assets/`: generated **concept** logo, icon and UI exploration artwork. They are **not** final trademark-cleared/platform-approved production assets. Visual mockup uses illustrative place names and routes, not verified data.

The generated adaptive icon foreground was created by automated background removal; manually inspect its mask/edges and re-export a production SVG or vector asset prior to use.
