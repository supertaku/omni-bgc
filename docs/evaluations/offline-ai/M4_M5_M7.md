## Implementation and choices

- Unified facade rereads canonical storage on every query and before final rendering. SQL `CURRENT_FACTS` owns temporal/rights eligibility; complete approved citation lineage is rechecked. Menus require two approved relationship citations; unsupported prices/tags/allergens are removed and cannot satisfy budget/tag filters. Decimal strings become integer centavos.
- Research is a separate authority, only exposed under explicit non-negated user scope. It retains original branch/date/estimate/starting-price/rights qualifiers and never resolves an actionable canonical map ID. Operating offices require current approved service records and citations; research office candidates are never imported.
- Decoder limits JSON bytes, depth, object keys, array sizes, UUIDs, exact money, enums, duration and stop counts; duplicate/escaped duplicate keys, malformed Unicode, dangerous prototype keys and unknown capabilities fail closed. Host IDs replace model IDs. No confirmation/commit, route, SQL, file, network or arbitrary-code tool is registered.
- Orchestrator: maximum two provider rounds, four calls, 45-second deadline, request/turn epochs, global monotonic generation epochs, duplicate-call denial, bounded history/schema/observation envelope. Cancellation settles the caller without asserting native idle. Actual native ownership belongs to the provider.
- Prompts delimit compact retrieved values as untrusted JSON. Observations stay parseable after size bounding. Deterministic cards carry actual citation membership. General prose is limited to explicitly recognized general/greeting/help turns, streamed by validated complete sentences; unsupported local factual clauses are withheld. Factual queries receive source-backed cards and explicit limitations.
- Optional embeddings/vector RAG remains **DEFERRED_BY_DATA**: no rights-cleared, approved passage corpus or measured semantic-retrieval need was established. No second factual database or speculative embedding runtime was introduced.
