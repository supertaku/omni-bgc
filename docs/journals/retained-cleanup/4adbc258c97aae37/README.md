# Original city-family artwork

Sixteen original sprite samples: ten façade families, four vegetation silhouettes,
grass and paving. Rebuild them and the native 1x/2x atlas with
`pipelines/map-pack/build.py`. The editable procedural drawing code is the source;
these PNGs are review samples and are packed into the installed offline atlas.

Façades are illustrative repeating motifs. They do not claim measured window
positions, building materials, roof equipment, entrances or landscaping. Family
selection uses retained source building/use tags; unknown buildings stay generic.
The exact source footprint is used at every presentation tier.

Project-authored internal artwork, `LicenseRef-Omni-BGC-Internal`; no third-party
photos, franchise assets or external redistribution permission. Geometry remains
separately subject to ODbL and the repository's distribution-review gate.
