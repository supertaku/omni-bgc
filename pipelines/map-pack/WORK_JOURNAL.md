## Decisions and implementation

- Installed MapLibre React Native 11.5.0 uses Android Native OpenGL 13.6.1 (package Gradle property and prior release dependency model). [Issue 4360](https://github.com/maplibre/maplibre-native/issues/4360) identifies missing APK-asset byte-range reads. [Fix 4602](https://github.com/maplibre/maplibre-native/pull/4602) merged September 24, 2026. The [13.6.1 tagged implementation](https://raw.githubusercontent.com/maplibre/maplibre-native/android-v13.6.1/platform/android/MapLibreAndroid/src/cpp/asset_manager_file_source.cpp) still returns the entire asset and omits `resource.dataRange`. Therefore the previous fallback `pmtiles://asset://` is incompatible. An arbitrary Expo/native dependency upgrade was rejected.
- `bundled-style.ts` copies every exact bundled resource through Expo's installed Android AssetFile support (`asset:///`), verifies byte counts and SHA256, then atomically moves the staged directory into an inventory-addressed private location. Native rendering receives `pmtiles://file:///`; glyphs and sprites also use private files. The existing reviewed active stylepack loader and trust registry are preserved. Failed/partial installations never publish a new directory. This is static/mock validation; native confirmation is pending.
- Original procedurally authored grass, paving, three tree variants, shrub, eleven category pins, origin and destination form 19 sprite entries at matching 1x/2x densities. Editable source lives in `build.py`. No borrowed game assets or new external dependencies. Gardens and paving remain confined to source polygon layers; trees remain actual sourced tree points. No invented roads, crossings, entrances, routes, or building footprints.
- Buildings use calm pastel families only where `building` tags explicitly classify them; unknowns retain a generic palette. Height and roofs remain visual parameters in metadata. Extrusions fade in between zoom 15/16, flat mode hides extrusions and retains source footprints, and navigation suppresses decorative texture/trees and browse pins.
- Selected place has a separate halo/pin/label, source-level clusters and category sprites replace dots. Candidate status is preserved internally while the parent-authorized historical directory can display without demo/pilot banners. Approved transit and validated route requirements remain unchanged. Route has white casing, blue center and a destination symbol.
- Camera focus reserves sheet/side-pane padding; routes/transit/itineraries fit their real coordinate bounds. Reset orientation and explicit flat mode are supported. OS reduced motion disables transitions. Native tap events continue to drive selection; dragging selection and sheet gesture conflicts require device verification. Parent must retain MapCanvas mounting across tab changes.
- Landmark registry is generated separately from exact retained footprint IDs. Its anchors are source-footprint interior points clipped to the existing service polygon. Generic extrusion asset families make no architectural likeness claims. Registry is an extension point; custom landmark artwork/geometry was deferred because no verified facade assets or supported native extension was supplied.
