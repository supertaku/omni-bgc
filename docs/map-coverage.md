These are supplemental counts after reconciliation, not a total BGC feature census. It is rendered from a **317,964-byte** tiled archive at zooms 14–18, overzoomed through 20. ## Rebuild and limits

Install build-only `scripts/map-requirements.txt`, then run `python scripts/build-map-context.py`. This also regenerates coverage; `python scripts/build-map-coverage.py` regenerates its manifest alone. Build dependencies are not mobile dependencies. `node scripts/check-map.cjs`, `python scripts/check-map-coverage.py` and `python scripts/check-context.py` validate resource receipts, metric buffer and geometry. The coverage builder pins the original reviewed coordinates independently of the registry's declared hash. Keep OSM attribution and ODbL notices. Existing internal-preview/distribution restrictions still apply.

The existing Python pipeline is retained: pinned local XML inputs, explicit multipolygon assembly, missing-node/unclosed-geometry rejection, source/derived geometry receipts, deterministic gzip and sorted tile emission already meet this bounded dataset's needs. Introducing Planetiler would require a separate input conversion/schema and JVM build without solving a demonstrated local generation blocker; it is not adopted. Reconsider for a larger PBF regional import, measured build-time problem or unresolved tile geometry defect. Neither pipeline permits caching OSM Foundation public raster tiles.

Coverage depends on source mapping; genuine source gaps remain possible. Host checks do not establish phone frame pacing, GPU cost, memory use, or visual acceptance. The owner should pan and zoom through the supplied screenshot views in airplane mode and check landmarks, neighborhood continuity, clusters and selected markers.
