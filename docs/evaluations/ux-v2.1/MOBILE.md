## WHY / HOW / rejected alternatives

Reuse pager and mounted screen state because camera, conversation, scroll and drafts must survive navigation. Reject full-screen pan recognizers because native map exploration and Assistant horizontal scroll must never switch screens. Require four aligned opposing peaks plus magnitude/time gates because a single spike also describes taps/pickup/pocket movement. Keep cooldown when lifecycle resets because changing screens itself must not allow immediate reversal. The initial private JSON preference approach avoided canonical/saved-schema changes but was superseded and removed under the user's final no-Settings instruction. Show only source-supported projected fields or marked fictional metadata rather than deriving hours/services from brand assumptions. Adapt existing Sheet using its header responder rather than adding another gestures/navigation stack. Use the measured pager viewport because global window metrics can lag keyboard layout and percentage height limits did not keep the initial search header visible on the device.

Initial calibration: linear peak1.15g, raw magnitude1.4g, gravity filter450ms, warmup300ms, opposite-peak spacing90–330ms, four peaks within1100ms, cooldown2500ms. These values remain provisional until intentional-shake and walking measurements on the connected phone. No measured-device performance or completed motion acceptance is claimed by this workstream.

Remaining physical-motion acceptance: real shake both directions, ordinary walking/pickup/pocket/rotation, repeated-shake cooldown and measured thresholds. Host lifecycle tests do not substitute for native sensor measurements. Chat/Back, native map search/peek, detail drag/collapse, selected-place retention and the search keyboard correction now have parent device evidence as listed above. Large text/landscape/TalkBack and other unlisted checks must be reported only where corresponding parent evidence exists. Preference restoration is superseded and excluded. Device screenshots/videos and integrated decision IDs remain parent-owned; parent explicitly ACCEPTs the final milestone after reviewing remaining evidence and limitations.
