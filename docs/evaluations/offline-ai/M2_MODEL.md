## Implementation and rationale

`ModelManager` serializes setup and exposes subscribe/status/recover/install/activate/rollback/remove/removeInstalled. `createExpoModelManager()` returns one shared setup owner. Explicit user initiation and license acknowledgment are required; only `install({kind:'download',...})` reaches networking. User-selected imports accept validated file/content URIs; arbitrary remote URLs and private-model self-import are rejected. Setup never runs on app startup.

The Expo adapter streams bounded file/network writes to a private checksum-named partial. It checks Range, exact content length when available, byte overflow/truncation, pinned source URL and reviewed final HTTPS domains. A server ignoring Range restarts the partial. Aborted transfers retain partial bytes for explicit retry; a final checksum mismatch clears the partial. SHA256 is streamed by the native bridge, avoiding a multi-GB JavaScript byte array or Expo Crypto digest. Atomic same-directory move avoids a second full staged copy; disk preflight retains a 256 MiB reserve and leaves prior artifacts intact.

The separate `omni-ai-model-index.sqlite` uses FULL synchronous transactional pointer commits. Staged data is never implicitly active. Restart rehashes pointer artifacts and checks catalog/path identity. Corrupt active pointers recover only from a verified previous candidate; malformed staging does not discard a prior recovery pointer. A failed commit leaves the old pointer in place. Referenced files are not deleted by ordinary staging cleanup. Explicit uninstall first clears corresponding pointers transactionally, then deletes, and rejects any held native engine lease.

`ModelResourceCoordinator.withModelMutation` excludes pointer/file mutation while the provider owns native model resources. `createProviderSmokeRunner` uses the real provider to load, generate nonempty text, start a second generation, cancel after the first actual delta and await native idle acknowledgment, release, reload, regenerate, release, then commit active. Immediate caller cancellation is not native idle proof. Any failed smoke or commit leaves the prior active pointer. The runner is called only for an explicit native trial; host tests use labeled controlled bridges and cannot establish real inference.
