# Offline map coverage and provenance

The reviewed `gex` PMTiles archive remains the detailed 2.5D center. Its service bounding box is longitude 121.0455–121.0584, latitude 14.5437–14.5596, with 149 z14–18 tiles. Its source is a September 2026 historical OSM snapshot marked `CANDIDATE_HISTORICAL`; its resource bytes, style, inventory, approval, and High Street fallback are unchanged.

The surrounding display context comes from sixteen bounded [OpenStreetMap API 0.6 map extracts](https://api.openstreetmap.org/api/0.6/map) fetched on 2026-10-20 UTC across longitude 121.035–121.070, latitude 14.530–14.575. The API rejected a single request under its 50,000-node limit, so the bounding box was divided into a 4 × 4 grid. The exact XML responses are retained as gzip files in `assets/generated/context/source/`; [provenance.json](../assets/generated/context/provenance.json) records each byte count and SHA-256, plus the derived GeoJSON checksum. Source attribution is **© OpenStreetMap contributors, ODbL 1.0**, also accessible from the map's attribution control. The new context is drawn from exact OSM node coordinates and whole ways; it is display-only and cannot supply navigation or directory facts.

The derived [context.json](../src/map/context.json) contains source building footprints, road and path ways, green and water polygons, and one St. Luke's label; exact counts are in the provenance receipt. Buildings are retained only within 0.004° of the detailed center to cap phone memory and bundle size; roads, paths, green and water ways extend across the requested bounding box. The newer context does not paint over the gex tile audit's display envelope: roads and paths are clipped exactly at that boundary, keeping their original source vertices outside it; polygons intersecting it are omitted whole. This can leave polygon gaps at the boundary. OSM API coverage is also limited by what contributors mapped; polygons built from relations and ways with missing nodes are omitted. No raster tiles are fetched or cached.

The St. Luke's Medical Center Global City label uses current OSM node `7597467285` at `[121.0482529, 14.554675]`, and the [hospital's official address](https://www.stlukes.com.ph/contact-us) confirms its location at Rizal Drive, 32nd Street and 5th Avenue. It is a map label, not a new directory or routing record. Its building way appears in the source within the existing detailed pack area.

The central building facades use ten original, repeating [project-generated tiles](../assets/map-facades/manifest.json) installed as runtime MapLibre images. The visual family comes from the reviewed pack's existing `facade_pattern` property; the new textures do not claim to reproduce a building's actual facade. The pinned PMTiles sprite atlas remains byte-identical.

Thinking Machines Data Science's [own contact page](https://old.thinkingmachin.es/contact/) currently confirms only Bonifacio Global City, Taguig. A [CTCN member profile](https://www.ctc-n.org/networking-and-collaboration/network-members/thinking-machines-data-science-inc) lists Twenty-four Seven McKinley Building, 24th Street corner 7th Avenue, but that profile dates to 2023 and does not establish the current office or floor. No office pin was added.

Run `python scripts/build-map-context.py` to regenerate the GeoJSON from the retained extracts, then `node scripts/check-map.cjs` to verify source/output hashes, feature counts, and center exclusion. Host checks verify resource bytes and geometry constraints; visual quality, performance, and installation still need owner testing on a phone.
